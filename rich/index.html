Рич-контент Ozon: размеры картинок и требования

Рич-контент — это блоки из картинок, заголовков и текста под фото карточки Ozon. Площадка называет его бесплатным маркетинговым инструментом, который превращает карточку в небольшой лендинг. Ниже — что проверить до сборки, чтобы конструктор принял макет с первого раза. Цифры взяты из разборов справки Ozon и документации конструктора; ссылки — внизу страницы.

Размеры картинок

ВерсияСоотношение сторонМинимальный размер
Телефон1:1от 640×640 px
Компьютер, широкая2:1от 1416×708 px
Компьютер, квадрат1:1от 708×708 px

Предел для одной картинки — 16 мегапикселей. Не путайте эти размеры с фото в галерее карточки: там вертикальный формат 3:4, подробнее — на странице требований к фото.

Две версии каждой картинки

Для каждого блока нужна картинка для компьютера и отдельная для телефона. В коде JSON это поля src и srcMobile. Без обеих версий конструктор не даст применить результат.

Файлы и ссылки

  • Форматы — JPG, JPEG или PNG, вес файла — до 10 МБ.
  • GIF лучше не использовать: по пересказам справки Ozon, с ними карточка долго загружается.
  • Если картинка добавляется по ссылке, ссылка должна быть прямой и заканчиваться на .jpe, .jpeg, .jpg или .png. Яндекс Диск для этого не подходит.
  • Ссылка с картинки может вести только на товар Ozon, на внешние сайты — нельзя.
  • Значок «Честного знака» в блоки не ставят: отметку площадка добавляет сама.

Текст в блоках

  • Заголовок блока обрезается после двух строк. Пишите коротко, в три–пять слов.
  • Не добавляйте картинки без текста. По пересказам справки Ozon, тогда внешние поисковые системы не смогут проиндексировать карточку.
  • Главную выгоду пишите крупно в первом блоке, подробности — в следующих.

Где собрать и как добавить

Рич-контент собирают в визуальном редакторе, где блоки перетаскивают мышью, или в песочнице, где правят код JSON. В личном кабинете путь такой: «Товары» → «Список товаров» → «Редактировать товар» → вкладка «Медиа» → блок «Rich-контент». Для многих товаров сразу подойдёт шаблон XLS со столбцом «Rich-контент JSON».

Что рич-контент не исправит

Блоки работают поверх карточки и не заменяют её основу. Пустые обязательные характеристики и неверные габариты останутся такими же, сколько блоков ни добавить. Поэтому сначала пройдите чек-лист публикации, потом беритесь за оформление. Тезисы для блоков поможет составить промпт из раздела «Инфографика», а длину текста — бесплатная проверка текста.
